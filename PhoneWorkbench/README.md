# 手机管理工作台 v0.1.0

Python 3.10+ 本地源码框架，无第三方 Python 依赖。数据保存到 SQLite。

## 功能与状态

- 设备与当前登录账号登记，设备标识唯一。
- 目标账号管理：分组、账号标识、主页、头像参考和人工确认状态。
- 人工核验任务：状态流转、同设备互斥、重启后暂停。
- 内容记录：作品链接去重、任务与目标账号关联检查。
- 操作日志和单实例锁。
- 影刀适配入口已建立，当前返回未配置。

当前设备信息由人工登记；截图和头像只保存参考路径。任务按钮仅推进人工核验状态，“完成”表示人工核验完成。自动设备发现、搜索、身份识别和互动执行尚未实现；记录编辑、删除与批量导入尚未提供。

完整需求及随机点赞、评论、转发规则见 `docs/架构说明.md`。养号不在项目范围内。

## Windows 启动

1. 将 `PhoneWorkbench` 放到 `D:\备份文件\项目库\抖音自动发布工具`，保留现有影刀目录。
2. 确认已安装 Python 3.10 或更新版本。环境检查见 `docs/交给本地AI.md`。
3. 双击 `启动工作台.bat`，保持控制台打开，访问 `http://127.0.0.1:8765`。
4. 登记设备和目标账号，创建人工核验任务，保存内容记录。
5. 退出时在控制台按 Ctrl+C。

命令行启动：在项目目录运行 `python run.py` 或 `py -3 run.py`。不自动打开浏览器使用 `python run.py --no-browser`。端口占用时关闭已启动实例，或使用 `python run.py --port 8766`。本包需要 Python，不包含 EXE。

## 数据备份

首次启动创建 `data/workbench.db`。备份或恢复前关闭程序，然后复制整个 `data` 文件夹。交付包不包含 `data` 或用户账号资料。

## 目录

| 文件或目录 | 职责 |
|---|---|
| run.py | 启动入口 |
| app/server.py | 本机 HTTP 接口 |
| app/store.py | 数据保存与任务状态 |
| app/instance.py | 单实例锁 |
| app/adapters/yingdao.py | 影刀适配入口 |
| web | 管理界面 |
| docs | 架构、安装与验证说明 |
| tests | 业务、接口与前端逻辑检查 |
| data | 运行时生成的数据 |

## 开发检查

Python：`python -m unittest discover -s tests -v`。

前端逻辑：`node tests/test_ui.cjs`。Node 仅用于开发检查，运行工作台不需要 Node。
