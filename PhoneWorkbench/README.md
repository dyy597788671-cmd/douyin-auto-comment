# 手机管理工作台 v0.1.0

这是可以在本地启动的项目基础框架。数据保存在 SQLite 文件中，不依赖在线数据库，不需要填写 AI API 密钥。

## 当前完成

- 设备与当前登录账号登记，设备标识唯一。
- 目标账号库，分组、账号标识、主页、头像参考和人工确认状态。
- 人工内容核验任务，状态流转、同设备任务互斥。
- 作品与身份核验记录，作品链接去重、任务与目标账号一致性检查。
- 操作日志，程序重启后将进行中的任务暂停，保留已保存数据。
- 独立的影刀适配层，当前明确显示尚未接入。

完整需求流程保留“身份核验后返回内容页，随机点赞、评论、转发”的动作节点及原有随机规则；互动动作继续保留为项目功能需求，当前基础框架尚未实现。暂停的是多账号养号流程。设备信息目前是人工登记，截图和头像仅保存参考路径，不自动打开文件。点击“开始核验”只改变人工核验任务状态，不会向手机发出操作；“完成”仅表示人工核验完成，不代表完整业务流程已完成。

完整需求与当前已开发子流程的区别，见 `docs/架构说明.md`。不能因随机互动节点尚未实现而将原始流程改成在身份核验处结束。

## Windows 启动

1. 将整个 `PhoneWorkbench` 文件夹放入 `D:\备份文件\项目库\抖音自动发布工具`，不要覆盖现有影刀目录。
2. 确保电脑已安装 Python 3.10 或更新版本。若不确定，将 `docs/交给本地AI.md` 全文发给本地 AI。
3. 双击 `启动工作台.bat`。保持弹出的控制台打开，浏览器会打开 `http://127.0.0.1:8765`。
4. 先登记设备与目标账号，再创建人工核验任务。
5. 退出时在控制台按 Ctrl+C。下次启动仍可看到已保存的数据。

如果端口占用，先关闭已启动的工作台，或者运行 `python run.py --port 8766`。命令行也可用 `py -3 run.py`。本包是源码框架，不是无需 Python 的 EXE。

## 数据与备份

首次运行会创建 `data/workbench.db`。先关闭程序，再复制整个 `data` 文件夹即可备份；恢复时也应关闭程序。不要把正在运行的 SQLite 文件单独拷贝作为备份。

`data` 不在交付包中；交付包不含用户账号、连接信息或演示数据。

## 项目目录

| 目录或文件 | 职责 |
|---|---|
| run.py | 启动入口 |
| app/server.py | 仅监听本机的 HTTP 接口 |
| app/store.py | 数据保存与任务状态规则 |
| app/adapters/yingdao.py | 影刀接入边界 |
| web | 本地管理界面 |
| docs/架构说明.md | 模块与数据关系 |
| docs/交给本地AI.md | 安装检查与后续接入任务 |
| tests | 核心业务与接口验证 |
| data | 首次运行生成的数据目录 |

基础版暂未提供记录编辑、删除、批量导入、自动设备发现或自动搜索。后续接入应先核实用户现有影刀能力，不能用模拟成功代替实际连接结果。

开发验证：`python -m unittest discover -s tests -v`。
