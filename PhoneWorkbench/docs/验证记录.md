# 基础框架验证记录

日期：2026年10月3日。版本：0.1.0。

本次在交付制作环境中验证了以下行为，均通过：

1. 无效的设备或账号关联不能创建任务。
2. 重复设备标识不能保存。
3. 人工确认身份前需要抖音号或主页链接。
4. 并发启动同设备任务只有一个成功；暂停后可以让出设备，恢复时重新检查占用。
5. 非法任务状态变化被阻止，失败必须记录原因，终态不能直接恢复。
6. 数据持久化，重启后的进行中任务暂停并写入日志。
7. 作品链接去重，关联任务与目标账号一致性检查。
8. 单项目进程锁，避免另一个端口上的实例重置运行状态。
9. 本地 HTTP 创建与查询、无效请求及跨站提交检查。

另检查了 Python 编译、前端脚本语法、六个界面分区的渲染逻辑、空数据状态与文本转义。

当前未在用户 Windows 电脑、真实影刀环境或手机上验证。界面逻辑检查不等于真实浏览器的完整视觉与交互测试。Windows 双击启动、浏览器显示和影刀连接应由本地 AI 进行后续确认。

Python 验证：`python -m unittest discover -s tests -v`。

可选前端逻辑验证：`node tests/test_ui.cjs`，仅开发验证使用，不要求用户安装 Node 来运行工作台。
