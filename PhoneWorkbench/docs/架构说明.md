# 本地基础架构

代码版本：0.1.0。文档修订：1.4。

已实现设备、目标账号、人工核验任务、内容记录、日志与 SQLite 保存。影刀、真实手机和自动操作尚未接入。养号不在项目范围内。

## 完整业务需求

目标账号用于识别内容作者；执行账号绑定对应手机。每台手机按相同流程独立运行，操作参数随机。

1. 选择已绑定的目标账号、关键词和内容类型。
2. 在预设账号数量范围内随机选择执行账号，使用对应手机搜索关键词。
3. 筛选最新发布内容；图文选择相应类型，必要时下拉搜索结果。
4. 打开候选内容，再进入作者主页核对目标身份。
5. 身份不符则返回搜索结果继续查找；相符则返回内容页。
6. 在点赞、评论、转发中随机执行一至三个动作。

随机参数：每步操作时间设上下限；评论从预设回复池随机选择；参与账号数量在预设范围内随机选择。具体时间、账号数量范围和回复池内容待配置。

## 当前实现状态

设备与登录账号资料由人工登记，身份由人工核验。当前任务的“完成”仅表示人工核验完成。自动搜索、身份识别、随机参数配置和互动执行尚未实现。

## 模块分工

界面通过本机 HTTP 接口访问业务层，业务层将数据保存到 SQLite。影刀适配层独立于界面与数据库，手机调用经影刀适配层处理。设备登记状态与连接状态分别记录。

| 模块 | 输入 | 输出与状态 |
|---|---|---|
| 设备管理 | 手机标识、备注、型号、当前登录账号 | 登记记录，连接状态默认待确认 |
| 目标账号库 | 昵称、抖音号、主页、参考头像、分组 | 待确认或人工已确认的身份记录 |
| 核验任务 | 一个设备、一个目标、关键词、内容类型 | 待核验、核验中、暂停、完成、失败、停止 |
| 内容记录 | 标题、链接、作者、时间、截图参考、核验结果 | 持久化核验记录，链接去重 |
| 日志 | 保存操作与任务状态事件 | 带时间的最近 500 条操作记录，完整历史保留在数据库 |
| 影刀适配层 | 将来核实的影刀连接能力 | 当前返回未配置，无执行能力 |

## 数据关系

每个任务关联一个设备和一个目标账号。每个内容记录关联一个目标账号，可以关联一个任务；关联任务与内容的目标必须一致。日志关联记录类型和编号。

数据库内部编号与抖音号、手机标识分别保存，不能混用。目标账号与手机当前登录账号分别登记；当前登录账号是手工资料，尚未自动读取或确认。

## 状态规则

| 当前状态 | 允许转入 |
|---|---|
| 待核验 | 核验中、停止 |
| 核验中 | 暂停、完成、失败、停止 |
| 暂停 | 核验中、停止 |
| 完成、失败、停止 | 终态；新任务需另建 |

同一个设备只能有一个核验中的任务。暂停释放本地任务占用；恢复时重新检查占用。此规则目前仅约束本工作台中的任务，尚不能检测外部影刀流程或其他工具对手机的控制。

重启时核验中的任务转为暂停，由用户确认后恢复。创建记录与日志、任务状态与日志均在同一数据库事务中保存。此版任务由人工推进，不包含后台调度器。

## 本地接口

| 方法和路径 | 用途 |
|---|---|
| GET /api/health | 服务与适配层状态 |
| GET /api/state | 当前管理数据与日志 |
| POST /api/devices | 登记设备 |
| POST /api/targets | 保存目标账号 |
| POST /api/tasks | 建立人工核验任务 |
| POST /api/contents | 保存核验记录 |
| POST /api/tasks/{id}/status | 推进任务状态 |

接口只监听 127.0.0.1。界面与服务同源，不开放跨域调用，不向外部网站发送数据。

## 影刀接入前置条件

需取得实际版本、套餐、手机自动化指令列表、设备连接方式、单台连接结果，再确定数据交换与连接读取方式。调用方式与流程导入格式尚未确定。

首次接入先验证单台设备识别、当前登录账号读取和截图或内容读取，再验证两台独立运行，最后扩展至目标设备数量。记录返回数据、错误和验证结果。
