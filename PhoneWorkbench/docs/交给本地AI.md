# 本地 AI 安装与接入任务

## 部署与验证

1. 将包内 `PhoneWorkbench` 放入 `D:\备份文件\项目库\抖音自动发布工具`，确认 `PhoneWorkbench\run.py` 存在，保留已有影刀目录。
2. 检查 Python 3.10+；缺失时报告环境要求。
3. 在 `PhoneWorkbench` 内运行 `python -m unittest discover -s tests -v`。
4. 启动 `python run.py --no-browser`，打开 `http://127.0.0.1:8765`。
5. 验证设备、目标账号、核验任务和内容记录的保存与查询；重启后确认数据保留、进行中的任务转为暂停。
6. 检查 Windows 双击启动、浏览器显示和按钮交互。

当前设备登记与任务状态由人工维护。影刀适配入口 `app/adapters/yingdao.py` 返回未配置；自动搜索、身份识别和互动执行尚未实现。完整需求与随机规则见 `架构说明.md`。

## 接入所需环境

- Windows 版本、CPU、内存、Python 版本。
- 影刀版本、套餐、手机自动化与连接手机指令列表。
- 手机数量、型号、安卓版本、抖音版本。
- USB 或无线连接方式、一台手机的实际识别结果。
- 项目目录结构、影刀主界面与手机指令列表截图。
- 本地 AI 的文件读取、命令执行和截图能力。

环境收集阶段只检查与报告，不修改现有影刀配置。

## 接入顺序

1. 根据实际影刀能力确定数据交换和调用方式。
2. 在适配层实现单台设备识别、当前登录账号读取与截图或内容读取，记录实际结果和错误。
3. 验证两台设备独立运行与同设备任务互斥，再扩展至目标设备数量。

返回安装路径、环境信息、验证结果、访问地址、错误日志和待处理事项。
