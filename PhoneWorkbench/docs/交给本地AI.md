# 发给本地 AI 的安装与接入任务

请先安装和验证这个本地基础框架。用户不会编程，请你完成文件放置、命令执行、错误分析，并给出用户能直接操作的结果。

## 安装任务

1. 项目根目录：`D:\备份文件\项目库\抖音自动发布工具`。
2. 将包内 `PhoneWorkbench` 文件夹放到该根目录，形成 `D:\备份文件\项目库\抖音自动发布工具\PhoneWorkbench\run.py`。保留原有 `影刀` 与 `影刀安装目录`。
3. 检查 Python 3.10 或更新版本是否可用。缺失时先报告，不擅自安装新的外部软件；请用户明确安装后再继续。
4. 在 `PhoneWorkbench` 中运行 `python -m unittest discover -s tests -v`，再启动 `python run.py --no-browser`。
5. 打开本机工作台，确认能保存设备、目标账号、人工核验任务与内容记录；重启后数据存在，进行中的任务暂停。
6. 不填充虚构账号、不使用演示数据冒充真实设备、不把基础框架启动成功说成手机连接成功。

## 环境报告

请只检查并报告以下信息，不改变现有影刀环境：

- Windows 版本、CPU、内存。
- 影刀版本、账号版本或套餐，以及是否存在手机自动化和连接手机指令。
- 手机实际数量、型号、安卓版本、抖音版本，是否全部安卓。
- USB 或无线连接方式；是否有一台手机已被影刀真实识别。
- 本地 AI 工具及文件、命令、截图能力。
- 项目目录结构。
- 影刀主界面与手机自动化指令列表截图。
